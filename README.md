\# GCP Data Lakehouse \& Analytics Platform



An end-to-end GCP data engineering platform that ingests data from multiple sources, stores raw data in Cloud Storage, processes data using Apache Beam/Dataflow, transforms and models data in BigQuery and Dataform, orchestrates pipelines with Cloud Composer, and provides analytics through Looker Studio.



\## Architecture



REST API / CSV / PostgreSQL

&#x20;       ↓

Python Ingestion

&#x20;       ↓

Cloud Storage

&#x20;       ↓

Apache Beam / Dataflow

&#x20;       ↓

BigQuery

&#x20;       ↓

Dataform

&#x20;       ↓

Analytics Data Marts

&#x20;       ↓

Looker Studio
